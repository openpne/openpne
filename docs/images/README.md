# Pictures in the README

[README.ja.md](../../README.ja.md) show: the home page, a group's talk room and a diary entry, at
phone width.

They were taken from a freshly installed site filled with made-up content. No member, name, post
or address in them belongs to a real person or site, and the AI account's message was written by
hand like the rest.
