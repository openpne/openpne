# Third-party notices for the bundled themes

The theme packages in this directory are OpenPNE 3's `opSkinThemePlugin` themes (Apache License 2.0,
like OpenPNE itself) and carry these third-party works:

- Bootstrap 2.3.2 (`css/bootstrap.css`, `img/glyphicons-halflings*.png`, `js/bootstrap-dropdown.js`) — Apache License 2.0, Copyright 2012 Twitter, Inc.
- Font Awesome 4.0.3 (`css/font-awesome.css`, `fonts/`) — font: SIL OFL 1.1, CSS: MIT License.
- `cat` and `sunflower`: photographs from ぱくたそ (https://pakutaso.com); see each package's `license.txt` for the terms that continued use requires.
- `winter`: background photograph by Forest Wander (http://www.forestwander.com/), credited in the page footer while the theme is active.
- `cerulean*` and `bootstrap`: Bootswatch colour schemes.

The `cerulean*` packages' `bootstrap.css` opens with an `@import` of the Telex family from
fonts.googleapis.com, so a page wearing one of them fetches that stylesheet from Google, as it did
on OpenPNE 3.
