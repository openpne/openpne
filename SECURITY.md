# Security policy

## Supported versions

OpenPNE 4 is in alpha. A fix is published as a new release (`v4.0.0-alpha.N`); an earlier alpha is
not patched, and `main` between releases is the development line.

## Reporting a vulnerability

Report it privately through this repository's advisory form:
<https://github.com/openpne/openpne/security/advisories/new>

Do not open a public issue or pull request for it. A report is easiest to act on when it says:

- the release or commit you tested;
- what an attacker gains, and what they need first (an account, a role, a setting);
- the steps, or a request, that show it.

## What to expect

Reports are read and answered on a best-effort basis; the project does not commit to a response
time. Please keep a report private until a release that fixes it is published. There is no bug
bounty.

## Scope

This policy covers the OpenPNE code in this repository. A problem with one site — its
configuration, its hosting, or what its members have posted — goes to that site's operator.
